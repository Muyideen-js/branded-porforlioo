# Yusuf Muyideen - 3D Branded Portfolio

Interactive 3D Portfolio Website and Desktop OS Showcase for **Yusuf Muyideen** — Software Developer & AWS Cloud Practitioner.

## Quick Start

```bash
# Install dependencies
npm i

# Run local development server
npm run dev

# Build for production
npm run build

# Start Express server
npm start
```

## Tech Stack
- Three.js (3D WebGL Room & Monitor Screen)
- React & TypeScript (UI Overlays)
- Webpack 5
- Node.js & Express
